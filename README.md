# ybhatta.com

Personal website of Yubaraj Bhatta — a single static page (`index.html`) hosted free on GitHub Pages at https://www.ybhatta.com.

- `index.html` — the whole site (HTML, CSS and JS in one file)
- `resume.pdf` — résumé linked from the site
- `CNAME` — tells GitHub Pages to serve the site at www.ybhatta.com

To update: edit `index.html` and push to `main`; GitHub Pages redeploys in about a minute.
